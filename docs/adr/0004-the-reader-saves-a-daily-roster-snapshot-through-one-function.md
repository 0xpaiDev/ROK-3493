# The reader saves a daily Roster Snapshot through one function

The Roster job fetches each day's Kingdom stats from Lilith with the token of the Reader Account, a separate account made for this Kingdom and alliance. It is the only writer of Roster Snapshots: once the job exists, the Council has no business uploading them.

A Governor missing from the stats becomes Inactive, never Migrated, because absence has no single meaning: a Governor can drop off the list after being away for a while, or can have migrated to another Kingdom.

Which Governors are checked for absence is deliberately not part of this decision. Today it is the Top 200, which may change with the Kingdom's size or become the main alliance's Governors.
